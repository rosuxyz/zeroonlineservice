# Zero TopUp Hub

Premium Game Top-Ups Marketplace.

## Tech Stack
- **Frontend**: Next.js 15 (App Router), Tailwind CSS, Framer Motion
- **Backend**: Supabase (Auth, DB, Storage)
- **State Management**: Zustand
- **Icons**: Lucide React

## Deployment
This project is optimized for Vercel. 
- Ensure all environment variables (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, etc.) are configured in the Vercel dashboard.
- The build process includes strict TypeScript checks to ensure production stability.

## Features
- Dynamic Game Marketplace with premium banners.
- Secure Checkout with PDF receipt verification.
- Admin Dashboard for order management and analytics.
- Real-time revenue tracking and user management.
